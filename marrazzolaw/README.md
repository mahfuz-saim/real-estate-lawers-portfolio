# Marrazzo Law Office website

A Next.js App Router website based on public information from the Marrazzo Law Office Facebook page and public directory listings. The office does not appear to have an independent website, so the contact details, office location and services have been kept to information found on those public sources.

```bash
cd marrazzolaw && npm install && npm run dev
```

Build for production with `npm run build`. Contact actions use the publicly listed phone number and directions; call ahead to confirm availability.
