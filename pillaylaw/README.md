# Pillay Law website

Standalone Next.js website for Pillay Law, Edmonton. Includes Home, About, Our Services, service detail pages, Team and Contact.

```bash
cd pillaylaw && npm install && npm run dev
```

Run a production build with `npm run build`. The enquiry form opens a pre-addressed email; no form data is stored by this frontend. Practice and contact information is drawn from the firm’s public website.
