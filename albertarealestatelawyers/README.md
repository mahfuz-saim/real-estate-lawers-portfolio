# Anderson Haak & Engels website

A standalone Next.js App Router site for the Alberta real estate law firm Anderson Haak & Engels.

```bash
cd albertarealestatelawyers && npm install && npm run dev
```

Production build: `npm run build`. The site includes dedicated pages for purchases, sales, refinancing, incorporations, wills and estates, lawyers and contact. Published price figures are marked as references and should be confirmed with the firm.
