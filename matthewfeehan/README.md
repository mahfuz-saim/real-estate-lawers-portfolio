# Feehan Law Office - Portfolio Website Template

A modern, responsive, and SEO-optimized portfolio website template for **Feehan Law Office** (Matthew F. Feehan, Barrister & Solicitor in Edmonton, Alberta), specializing in Wills, Estate Planning, Probate, and Real Estate Law.

Built with:
- **Next.js 15 (App Router)** & **TypeScript**
- **Tailwind CSS v4**
- **Motion for React** (Framer Motion) for smooth animations & entrance effects
- **Radix UI** primitives & **Lucide React** icons
- **SEO & Structured Data (JSON-LD)** for LegalService schema, Open Graph, Sitemap & Robots

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
