# HTM Law Edmonton website

Standalone Next.js App Router site for HTM Law LLP. It includes Home, About, Team, Resources, Real Estate, Wills & Estates, Business Law, Litigation and Contact pages.

```bash
cd edmontonlaw && npm install && npm run dev
```

Run `npm run build` for production. The contact form opens an email to the published reception address; this frontend does not submit/store form data.
