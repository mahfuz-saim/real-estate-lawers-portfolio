# Richards + Company portfolio site

Next.js App Router frontend for Richards + Company. To run locally:

```bash
cd richardslaw
npm install
npm run dev
```

Build for production with `npm run build`; serve with `npm start`. Update firm details and legal content in `app/page.jsx` and `app/layout.jsx` when adapting this template. Images are sourced from Unsplash and loaded remotely via CSS.
